# 噜噜查 · 拼音速启

一个**纯离线**的安卓启动器：输入两三个拼音字母就能秒开应用。核心解决三件事——**多音字不漏**、**任意字母能蒙**、**单手好按**。

- 包名：`com.lulucha.quick`
- 版本：**3.0.1**（versionCode 47）
- 系统要求：Android 7.0（API 24）及以上
- 权限：仅 `QUERY_ALL_PACKAGES`（读取已安装应用列表）

---

## 一、特性

| 能力 | 说明 |
|---|---|
| 拼音模糊搜索 | 全拼 / 首字母 / 任意子串 / 松散顺序，四层梯度打分 |
| 多音字全保留 | 「重庆银行」同时生成 `cqyh`、`zqyh`、`tqyh`，任一变体命中即算 |
| T9 通配 | 按 `7` 等于 `pqrs`，按 `77` 就能捞出 `QQ`；命中的字母会**标红** |
| 26 键 | 直接敲字母，键型「矮胖紧」（单手 40dp / 全屏 48dp） |
| 长按键弹候选 | 长按字母/数字键，浮出以该键开头的应用，点一下直达 |
| 长按应用操作 | 应用信息 / 分享名字 / 分享安装包 / 卸载 |
| 单手模式 | 整页收窄到 75%、贴左下或右下，顶栏一键切换三档 |
| 玻璃质感 | 白色半透明键帽、圆角卡片、面板外系统级背景模糊 |
| 秒开 | 启动读本地缓存的应用列表，退出时静默重扫 |
| 学习排序 | 用得多的、最近用过的会自动往前排 |

## 二、搜索规则

| 你输入 | 命中逻辑 | 例子 |
|---|---|---|
| `wx` | 首字母前缀 | 微信 |
| `weixin` | 全拼前缀 | 微信 |
| `ix` | 全拼任意子串 | 微信（we**ix**in） |
| `xn` | 字母松散顺序匹配 | 微信（wei**x**i**n**） |
| `cq` / `zq` | 多音字双读音都算 | 重庆银行（**chong**qing / **zhong**qing） |
| `yinhang` | 词组内任意子串 | 中国银行 |

打分梯度（匹配质量永远优先于使用频率）：

```
全拼整串相等  1010
全拼前缀      1000
首字母前缀     930
全拼子串       820 - 起点偏移
首字母子串     750 - 起点偏移
松散子序列     430 - 跨度惩罚   ← 「随便两个字母」靠这层
```

最终分 = 匹配分 × 1000 + 常用度加成 + 时效加成。

## 三、怎么用

### 两种键盘

顶栏 `T9` / `26键` 标签可切换，也可以点键盘上的切换键。

- **26 键**：直接敲字母，最精确。
- **T9 九宫格**：`abc=2 / def=3 … wxyz=9`，按键即通配匹配；底部「提交」启动当前第一个结果，「清空」清空输入。

两种键盘的退格键都支持**长按连续删除**。

### 长按

1. **长按字母键 / 数字键** → 弹出「已输入内容 + 该键」对应的应用（最多 12 个），点一下直接启动；
2. **长按搜索结果** → 底部弹出操作面板：应用信息、分享应用名、分享安装包、卸载。

### 单手模式

顶栏设置键左侧有一个「全屏 / 右单手 / 左单手」按钮，点一下换一种，也可以到设置里选。

单手模式下：

- 整页收窄到屏宽 75%、贴左下或右下，外面是**模糊后的桌面 + 10% 白雾**；
- 面板高度按「正好放下 6 个应用框」实测计算，不会切半行；
- 面板是 24dp 圆角卡片、带 6dp 投影；
- 点面板外任意位置**直接退出**（面板内点空白不会误退）。

### 其他

- 设置里可换背景图并调透明度，**只作用于面板内部**，面板外仍是模糊桌面；
- 可调键盘高度、字号、是否显示拼音提示；
- 「刷新应用列表」用于新装应用后立即更新（正常退出也会自动刷新）。

## 四、自己编译

需要 **JDK 17**、**Android SDK 34**、**Gradle 8.7**（仓库未带 wrapper）。

```bash
export JAVA_HOME=/path/to/jdk17
export ANDROID_HOME=/path/to/android-sdk

gradle assembleDebug     # app/build/outputs/apk/debug/app-debug.apk
gradle assembleRelease   # app/build/outputs/apk/release/app-release.apk
```

签名信息放在项目根目录的 `keystore.properties`（**不入库**）：

```properties
storeFile=keystore/your-release.jks
storePassword=YOUR_STORE_PASSWORD
keyAlias=your_alias
keyPassword=YOUR_KEY_PASSWORD
```

可复制 `keystore.properties.example` 改名后填写，再把 `.jks` 放进 `keystore/`。

### 多音字怎么处理

`assets/pinyin_dict.txt` 收录 2 万余汉字，其中近 5000 个多音字保留 2–4 个读音：

```
重	zhong,chong,tong
行	xing,hang,heng
乐	le,yue
```

构建索引时对应用名做**读音笛卡尔积**（上限 48 条），每条同时生成全拼与首字母串：

```
重庆银行
├─ cqyh  chongqingyinhang
├─ zqyh  zhongqingyinhang
├─ tqyh  tongqingyinhang
└─ …（去重后 9 条变体）
```

搜索时任一变体命中即算匹配——不做读音判断，直接全保留。

## 五、已知限制

1. **T9 输入的是数字**，按 `2` 匹配 `a/b/c`，要精确输入请切 26 键；
2. **多音字会带来少量噪音**（如「信」有古音 `shen`），排序会把它压到后面；
3. **应用名含生僻字**且不在字典内时可能搜不到，可在 `pinyin_dict.txt` 补一行解决；
4. **首次启动**读取应用列表约 0.3–1 秒（取决于安装数量），之后走缓存秒开；
5. 面板外的模糊依赖系统的跨窗口模糊（Android 12+），部分 ROM 关闭该能力时会退化为「薄雾 + 清晰桌面」。
